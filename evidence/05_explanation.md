# Architecture Explanation

The API layer in src/ai_service/api/routes.py receives HTTP requests, calls the service, and converts validation errors into HTTP 400 responses. The service layer in src/ai_service/services/ai_service.py holds the classification logic and has no knowledge of HTTP, so it can be tested directly. Configuration in src/ai_service/config/settings.py reads APP_NAME, APP_VERSION and DEBUG from the environment, which lets the same code run with different values locally and in Docker without editing source files. Logging in src/ai_service/utils/logging.py writes to stdout, so the same messages appear in the Uvicorn terminal and in docker logs. The Docker boundary is defined by deployment/Dockerfile, which packages requirements.txt and src/ into an image, and deployment/docker-compose.yml, which runs that image with port mapping 8000:8000 and injects the local .env file.
